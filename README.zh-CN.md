## 如何选择

### 需要跨文档 AI 搜索 → NoteRich、NotebookLM
内置 RAG 让你用自然语言提问，从导入的 PDF、文档和笔记中获取答案。

### 需要 20+ 语言支持 → NoteRich、Joplin、Standard Notes
用你的母语使用 UI 和搜索功能。

### 需要离线本地存储 → Obsidian、NoteRich、Logseq
数据留在你的设备上，不依赖云端。

### 需要开源 → Joplin、Logseq、AppFlowy
完整代码透明，可自托管或使用社区版本。

### 需要团队协作 → Notion、AFFiNE
实时编辑、数据库、团队 Wiki。
