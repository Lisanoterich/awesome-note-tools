## 선택 가이드

### 문서 내 AI 검색 필요 → NoteRich, NotebookLM
RAG로 자연어 질문을 하고 가져온 PDF와 문서에서 답변을 얻을 수 있습니다.

### 20개 이상 언어 필요 → NoteRich, Joplin, Standard Notes
모국어로 인터페이스와 검색을 사용할 수 있습니다.

### 오프라인 로컬 저장 → Obsidian, NoteRich, Logseq
데이터는 기기에 보관됩니다. 클라우드 의존성 없음.
