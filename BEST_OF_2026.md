## Detailed Comparison

### 1. NoteRich ⭐ AI Search King
- **RAG Search**: Ask questions in natural language, get answers from your notes
- **Languages**: 41 native languages
- **Document Support**: 10,000+ PDFs, DOCs, web pages
- **Price**: Free tier / PRO $39.90/year
- **Best for**: Researchers, multilingual users, document-heavy workflows

### 2. Obsidian ⭐ Plugin Powerhouse
- **Storage**: Local Markdown files — you own your data
- **Plugins**: 1,500+ community plugins
- **Graph View**: Visual knowledge connections
- **Price**: Free / Sync $4/mo / Publish $8/mo
- **Best for**: Power users, developers, local-first advocates

### 3. Notion ⭐ All-in-One Workspace
- **Features**: Databases, wikis, tasks, calendar, AI
- **Collaboration**: Real-time team editing
- **Templates**: Massive community library
- **Price**: Free / Plus $10/mo / Business $15/mo
- **Best for**: Teams, project managers, all-in-one needs

### 4. Logseq ⭐ Open Source Outliner
- **License**: AGPL-3.0 — fully open source
- **Format**: Org-mode + Markdown
- **Features**: Bidirectional linking, flashcards, PDF annotation
- **Price**: Free
- **Best for**: Open source advocates, outliner fans

### 5. Joplin ⭐ Privacy-First
- **Encryption**: E2EE (opt-in)
- **Sync**: Cloud ($2.99/mo) or self-host
- **Languages**: 30+
- **Price**: Free / Cloud $2.99/mo
- **Best for**: Privacy-conscious users, cross-platform needs

### 6. Mem ⭐ AI-Native Notes
- **AI**: Automatically surfaces related notes
- **Search**: Semantic, context-aware
- **Format**: No folders — AI organizes for you
- **Price**: $14.99/mo
- **Best for**: AI-first note takers

### 7. Reflect ⭐ AI Journaling
- **AI**: GPT/Claude prompts to query your notes
- **Features**: Daily notes, backlinks, voice notes
- **Encryption**: E2EE
- **Price**: $10/mo
- **Best for**: Daily journaling, AI-enhanced reflection

### 8. Standard Notes ⭐ Security First
- **Encryption**: E2EE by default
- **Extensions**: Markdown, spreadsheets, to-dos
- **Languages**: 30+
- **Price**: Free / Productivity $7.50/mo / Professional $12/mo
- **Best for**: Security-critical work, journalists

### 9. Capacities ⭐ Object-Based PKM
- **Model**: Objects (People, Projects, Books) instead of folders
- **UI**: Clean, modern design
- **AI**: Coming soon
- **Price**: Free / Pro $10/mo
- **Best for**: Visual organizers, object-based thinkers

### 10. AnyType ⭐ Local-First Workspace
- **Storage**: Local + P2P sync
- **License**: Open source
- **Features**: Databases, relations, templates
- **Price**: Free
- **Best for**: Notion alternative, local-first fans
